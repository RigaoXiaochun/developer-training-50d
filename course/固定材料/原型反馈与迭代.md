# 界面评审材料

Q03、Q04 使用。选择至少两条反馈，在原型上记录实际操作、问题、涉及的控件及调整后的复测结果。

| 反馈 | 核对事项 |
|---|---|
| 手机筛选区挤占内容 | 检查视口、信息保留、触摸范围和操作顺序 |
| 同一种操作在不同页面样式不一 | 核对共用控件、圆角、焦点与错误样式 |
| 工单标题过长时操作按钮被挤出 | 核对截断、可收缩区域和标题全文入口 |
| 请求失败后页面仍提示保存成功 | 核对响应、按钮恢复与草稿保留 |
| 工单增多后列表响应变慢 | 分别记录查询、传输和 DOM 开销 |
| 修改控件后其他页面出现样式问题 | 列出共享依赖，并按旧用例复测受影响页面 |

提交修改前后截图和关键差异。未复现的问题可记录实际结果并另选反馈。
