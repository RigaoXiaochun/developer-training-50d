# 性能测量与版本交付

分别记录数据库查询、网络传输和页面渲染。通过 SQL 筛选与 LIMIT 限制结果；游标负责续页，查询仍按当前身份过滤。界面应控制列表 DOM 节点数。

使用 [负载条件](../固定材料/现场与整合变体.md#q18-负载条件) 在本地训练库测量。记录机器、Node 版本、SHA、索引、查询计划和原始耗时。采用最近秩法计算 p50 和 p95，保留最大值、失败与超时。指标只针对本次训练环境。

Q18 可在已启用 SQLite 和游标接口的独立训练目录中运行以下命令。第一条生成 10000 条性能样本并测量，保留报告供对照。再次测量时使用第二条，保持样本和并发条件相同。

```sh
npm run perf -- --seed 10000 --confirm-local-seed
npm run perf -- --samples 500 --concurrency 10
```

从 `.local/performance/` 取出本次报告，作为验证附件提交。

候选版本确定后核对构建、迁移、兼容与恢复条件。通过本地预览验证主要 API 路径。分别演练代码撤销和数据恢复，并核对旧版本能否使用已迁移的数据。
