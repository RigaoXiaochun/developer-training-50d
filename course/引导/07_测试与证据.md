# 验证与记录

| 命令 | 核对范围 |
|---|---|
| `npm test` | v1 基线行为 |
| `npm run test:learner` | 学员新增测试 |
| `npm run test:core -- Qxx` | 独立函数 |
| `npm run typecheck`、`npm run build` | 类型与构建 |
| `npm run check:ui -- Qxx` | 浏览器与界面 |

正常联调调用实际训练 API；模拟网络失败时注明方法。故障回归需记录修复前的失败和修复后的通过。缩放、键盘、重启、权限、版本与幂等是否需要验证，以任务书为准。

同一候选版本的记录应包括完整 SHA、环境、复现步骤、预期、实际和附件位置。对跳过或暂缺条件的检查注明原因。
