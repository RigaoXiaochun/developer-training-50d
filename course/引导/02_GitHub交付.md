# Git 和 GitHub 练习

第 1 题先在克隆的本地训练工程提交。第 2 题从上一次提交新建分支，先看 `git diff`，逐项暂存后用 `git diff --cached` 复核，再提交。`git rev-parse HEAD` 给出本次提交的完整 SHA。

到 [GitHub Skills](https://github.com/skills/introduction-to-github) 用自己的账号做公开示例。练习建分支、开 PR、查看改动和合并。第 19 题可在公开示例练习 Actions，培训工程继续在本地跑检查。

在培训系统填写 SHA 和完成说明，附上本题源码与验证材料。`learning/Qxx/` 保留命令、结果和 `git show --stat --oneline HEAD` 输出。带教能打开的公开练习链接可以放在完成说明里。
