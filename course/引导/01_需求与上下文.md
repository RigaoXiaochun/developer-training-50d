# 工单台需求梳理

启动工程后打开 `http://127.0.0.1:4780/vue.html` 检查入口。工单页面的正式交互在后续任务实现。另开终端，在本地请求列表接口，核对模拟账号 `user-01` 的可见范围。

```sh
node -e "fetch('http://127.0.0.1:4781/api/training/v1/tickets', {headers: {'X-Training-Actor': 'user-01'}}).then(async r => console.log(r.status, await r.json()))"
```

运行 `npm test`，在 `tests/infrastructure/api.test.mjs` 中找到创建工单的用例，沿 `server/app.mjs` 的路由和 `server/domain.mjs` 的权限规则追到存储。用自己的话记录请求参数、校验结果和写入内容。

按角色逐项记录可操作对象、前置状态、成功结果和禁止情形。对照 [需求材料](../固定材料/业务原话与FAQ.md)，列出已确认、待确认和本次排除的事项。需求记录应包含实际文件和路由，便于审核时复现。

在开始工程改动前确认可修改范围、接口约束及验收步骤。提交时附至少一个能验证的异常场景。
