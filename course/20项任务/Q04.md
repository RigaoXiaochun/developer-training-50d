# 开发培训任务 Q04

## 工单列表、新建和详情

使用提供的样例数据实现列表、搜索、状态筛选、分页、新建与详情。详情按工单 ID 打开。实现加载、无结果、请求失败、提交中和字段校验反馈。说明仍使用样例数据的入口。

从 [原型反馈材料](../固定材料/原型反馈与迭代.md) 选择实际能复现的反馈，沿用 Q03 控件验证一条完整操作路径，并记录实际观察到的行为。

- 页面状态使用明确的 TypeScript 类型；表单文本域使用统一交互规则。

改动范围包括 `frontend/vue/`、`frontend/shared/`、`learning/Q04/`。任务分支为 `feat/q04-responsive-workbench`。

在 `exercises/Q04.ts` 独立完成 [`toCard`](../核心编码契约.md#q04-tocard) 并补充三个自拟反例。单独提交后再继续工程改动。

## 提交材料

提交桌面和手机操作记录、各异常状态的复现步骤及类型检查和构建结果。

在培训仓库提交 PR，并将 PR 链接、完整提交 SHA、完成说明及 PR 截图上传培训系统。将检查记录整理到 `learning/Q04/`，格式见 [交付记录](../模板/交付模板.md)。

## 验收要求

使用 20 条记录、60 码点标题、连续英文和 1000 字描述检查四种页面宽度。详情可读全文，表单反馈靠近对应字段，手机底部操作可触达。

```sh
npm run check:task -- Q04
npm test
npm run test:learner
npm run typecheck
npm run build
```
