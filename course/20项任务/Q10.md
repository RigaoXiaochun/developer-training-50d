# 开发培训任务 Q10

## 阶段验收二 · 接口与数据

用同一候选版本复查三类角色读写、非法字段、重复创建、版本冲突、重启持久化、归档与事件记录。运行基线、学员测试、类型检查、构建及浏览器测试。

- 核对实现与文档差异，列出待验证项；阻断问题修复后方可通过。

改动范围包括 `frontend/vue/`、`server/`、`tests/learner/`、`learning/Q10/`。任务分支为 `feat/q10-integration-gate`。

在 `exercises/Q10.ts` 独立完成 [`classifyFailure`](../核心编码契约.md#q10-classifyfailure) 并补充三个自拟反例。单独提交后再继续工程改动。

## 提交材料

提交候选版本、联调测试结果和失败复测记录。

在培训仓库提交 PR，并将 PR 链接、完整提交 SHA、完成说明及 PR 截图上传培训系统。将检查记录整理到 `learning/Q10/`，格式见 [交付记录](../模板/交付模板.md)。

## 验收要求

Q01 至 Q10 的独立编码检查应通过。提供参数化查询、事务、可见范围和幂等的验证证据。界面评分至少 85 分且无阻断问题。按抽取的样例现场修改，并用日语说明一次异常恢复，控制在两分钟。

```sh
npm run check:task -- Q10
npm test
npm run test:learner
npm run typecheck
npm run build
npm run test:acceptance -- Q10
npm run check:ui -- Q10
```

本项安排现场验收。

### 审核提问

选一次页面操作，说明它对应的请求、数据库写入和错误处理。

テストの範囲と、まだ確認できていない点を説明してください。
