# 开发培训任务 Q12

## 批量更新工单状态

实现管理者专用的 `POST /v2/bulk-status`。每项提交 ID 和版本，按约定校验状态、重复 ID 和数量上限。权限、版本检查、状态更新和事件记录应在同一事务中完成。

- 重复 ID 和数量超限返回 400；不可见返回 404；版本冲突返回 409。
- 达到 100 项后禁止继续选择，取消选择后恢复；批量提交前应有统一确认。

改动范围包括 `server/`、`frontend/vue/`、`tests/learner/`、`learning/Q12/`。任务分支为 `feat/q12-atomic-bulk`。

在 `exercises/Q12.ts` 独立完成 [`checkBulkVersions`](../核心编码契约.md#q12-checkbulkversions) 并补充三个自拟反例。单独提交后再继续工程改动。

## 完成后应能做什么

能实现带权限和版本检查的批量操作，在一条失败时让整批不写入，并让用户在跨页选择和冲突中仍能继续操作。

## 提交材料

提交一次成功记录、一项事务回滚的核验，以及桌面和手机上的跨页选择记录。

在培训仓库提交 PR，并将 PR 链接、完整提交 SHA、完成说明及 PR 截图上传培训系统。将检查记录整理到 `learning/Q12/`，格式见 [交付记录](../模板/交付模板.md)。

## 验收要求

验证 99、100、101 项以及不可见记录、版本冲突和数据库失败等情况。失败时不得部分写入或泄露不可见 ID。列表跨页保留选择，切换筛选时清空；冲突时保留选择并提供刷新入口。

```sh
npm run check:task -- Q12
npm test
npm run test:learner
npm run typecheck
npm run build
npm run test:acceptance -- Q12
npm run check:ui -- Q12
```
