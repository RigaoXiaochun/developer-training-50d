# 开发培训任务 Q19

## 候选版本检查与恢复演练

固定候选 SHA，执行基线、学员测试、核心函数检查、类型检查、构建与浏览器测试。从空工作目录启动本地预览，通过 API 验证工单主流程。对照 PR 的 Checks 页记录对应结果。

- 使用相同 SHA 核对构建产物、测试结果和恢复记录。

改动范围包括 `.github/workflows/`、`README.md`、`tests/learner/`、`learning/Q19/`。任务分支为 `feat/q19-release-readiness`。

在 `exercises/Q19.ts` 独立完成 [`releaseReadiness`](../核心编码契约.md#q19-releasereadiness) 并补充三个自拟反例。单独提交后再继续工程改动。

## 完成后应能做什么

能固定一份可发布的版本，让构建、测试和本地预览对应同一 SHA，并分别演练代码回退与数据恢复。

## 提交材料

提交候选版本、各项检查记录、预览验证和恢复演练记录。

在培训仓库提交 PR，并将 PR 链接、完整提交 SHA、完成说明及 PR 截图上传培训系统。将检查记录整理到 `learning/Q19/`，格式见 [交付记录](../模板/交付模板.md)。

## 验收要求

检查结果须对应同一候选版本。完成一次恢复演练，记录迁移重试条件、代码撤销和数据恢复的步骤及结果。注明尚未验证的环境或操作。

```sh
npm run check:task -- Q19
npm test
npm run test:learner
npm run typecheck
npm run build
npm run test:acceptance -- Q19
npm run check:ui -- Q19
```
