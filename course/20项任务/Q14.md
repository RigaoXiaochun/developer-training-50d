# 开发培训任务 Q14

## 编辑表单的草稿与冲突处理

区分表单原值、草稿、保存中、保存失败和版本冲突。请求只带允许编辑且实际变化的字段。离开未保存页面时弹出确认，取消后将焦点还给触发控件。

- 按字段展示错误信息，确认弹窗支持键盘与焦点返回，保存按钮在请求结束后恢复。

改动范围包括 `frontend/vue/`、`tests/learner/`、`learning/Q14/`。任务分支为 `feat/q14-complex-editing`。

在 `exercises/Q14.ts` 独立完成 [`changedFields`](../核心编码契约.md#q14-changedfields) 并补充三个自拟反例。单独提交后再继续工程改动。

## 提交材料

提交保存失败、离开取消和版本冲突的操作记录，并注明手机软键盘的验证情况。

向培训仓库提交 PR。在培训系统填写 PR 链接、完整提交 SHA 和完成说明，上传 PR 截图。检查记录放在 `learning/Q14/`，格式见 [交付记录](../模板/交付模板.md)。

## 验收要求

验证空字符串、`false` 和 `0` 的提交，检查重复点击、保存失败和离开操作。版本冲突后同时展示本地草稿和最新值，由用户确认是否重新提交。检查 320 px、200% 缩放和键盘操作。

```sh
npm run check:task -- Q14
npm test
npm run test:learner
npm run typecheck
npm run build
npm run test:acceptance -- Q14
npm run check:ui -- Q14
```
