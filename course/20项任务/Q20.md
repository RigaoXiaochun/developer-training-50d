# 开发培训任务 Q20

## 结业验收 · 需求交付

根据审核人抽取的小需求，提交范围说明及验收条件，再在本地分支完成实现、审查和回归。现场对两项抽取的核心函数或 SQL 说明行为并完成指定修改，用日语介绍成果，控制在两分钟。

- 验收以实际代码、提交差异和测试结果为依据。未通过项由审核人记录并安排补做。

改动范围包括 `frontend/vue/`、`server/`、`tests/learner/`、`learning/Q20/`。任务分支为 `feat/q20-ownership-assessment`。

在 `exercises/Q20.ts` 独立完成 [`contractDiff`](../核心编码契约.md#q20-contractdiff) 并补充三个自拟反例。单独提交后再继续工程改动。

## 提交材料

提交最终版本、源码、启动与验证步骤、已知限制和待办事项。

在培训仓库提交 PR，并将 PR 链接、完整提交 SHA、完成说明及 PR 截图上传培训系统。将检查记录整理到 `learning/Q20/`，格式见 [交付记录](../模板/交付模板.md)。

## 验收要求

20 项核心函数与工程材料须齐全。基础编码、工具协作和工程交付分别审核。界面评分至少 85 分且无阻断问题，工单主流程、SQL、权限及故障处理通过验证。

```sh
npm run check:task -- Q20
npm test
npm run test:learner
npm run typecheck
npm run build
npm run test:acceptance -- Q20
npm run check:ui -- Q20
```

本项安排现场验收。

### 审核提问

说明一项未覆盖的情况，以及安排验证所需的条件。

### 日语说明

ご自身で判断したことと、AIに任せたことを具体的に説明してください。

参考 [本项技术说明](../引导/10_现场说明.md) 和 [接口与数据规范](../契约/接口与数据.md)。
