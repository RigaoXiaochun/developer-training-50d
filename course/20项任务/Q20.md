# 开发培训任务 Q20

## 结业项目 · 设备借还系统

从 [设备借还系统任务书](../固定材料/结业项目任务书.md) 的业务原话开始。技术栈为 Vue 3、TypeScript、Node.js 和 SQLite。先把用户、操作、状态、权限与验收条件写进 GitHub 需求记录，向带教澄清关键问题，再开发一套可独立运行的完整系统。

从 Q19 已通过的版本建立 `feat/q20-ownership-assessment`。结业项目放在 `capstone/`，原工单练习的检查继续从仓库根目录执行。独立完成 [`contractDiff`](../核心编码契约.md#q20-contractdiff) 和本题三个自拟反例，单独提交后再进入工程部分。

## 提交材料

- GitHub 需求记录及确认结果、PR、最终提交 SHA、完整源码、验证记录与必要截图。
- `capstone/README.md` 写明启动、数据初始化或迁移、样例账号和完整业务复现步骤。
- 在 `learning/Q20/` 记录一次收到的原型反馈和对应的复测结果，说明你对需求的理解，以及哪些改动采用了工具的建议。

## 验收要求

审核人应能在干净环境从启动到完成一次已确认的设备借还流程。用持久化数据和测试证明权限拒绝、业务冲突、重启后查询等关键行为，并在桌面和手机实测。

从仓库根目录运行课程检查。

```sh
npm ci
npm run check:task -- Q20
npm test
npm run test:learner
npm run typecheck
npm run build
npm run test:acceptance -- Q20
npm run check:ui -- Q20
```

在 `capstone/` 运行结业项目自己的检查。

```sh
npm ci
npm run typecheck
npm test
npm run build
```

现场用最终提交演示，按指定的新边界独立修改并验证一处关键逻辑。可参考 [现场演示与日语说明](../引导/10_现场说明.md)。
