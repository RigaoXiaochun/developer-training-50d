# 开发培训任务 Q08

## 并发更新与创建幂等

按角色、字段和状态校验写操作。更新工单时同时匹配 ID 与版本，工单修改与事件写入放在同一事务。创建接口支持可选的 `Idempotency-Key`。

- 数据库对身份和幂等键设置唯一约束，并记录创建时间。
- 保持无幂等键的已有请求兼容；同键不同内容返回 409 IDEMPOTENCY_CONFLICT。

改动范围包括 `server/`、`tests/learner/`、`learning/Q08/`。任务分支为 `feat/q08-controlled-writes`。

在 `exercises/Q08.ts` 独立完成 [`canUpdate`](../核心编码契约.md#q08-canupdate) 并补充三个自拟反例。单独提交后再继续工程改动。

## 提交材料

提交直接接口测试，覆盖同键重试、旧版本更新和受限角色，并附事件计数。

在培训仓库提交 PR，并将 PR 链接、完整提交 SHA、完成说明及 PR 截图上传培训系统。将检查记录整理到 `learning/Q08/`，格式见 [交付记录](../模板/交付模板.md)。

## 验收要求

相同身份和幂等键重复发送相同请求时，返回原 201 和工单 ID。请求内容不同则返回 409。验证并发和重启后同一操作只产生一条工单和一条 CREATED 事件，旧版本更新和权限不足时不得产生写入。

```sh
npm run check:task -- Q08
npm test
npm run test:learner
npm run typecheck
npm run build
npm run test:acceptance -- Q08
```
