# 开发培训任务 Q09

## 工单页面接口联调

在现有页面接入本地工单 API，统一处理接口错误。切换角色、筛选或分页时取消旧请求或丢弃过期响应。创建请求超时后复用当次幂等键；更新返回 409 时保留草稿，显示最新记录并由用户确认后重试。

- 切换身份时先清除上个身份的列表与详情；每次新的创建操作使用新幂等键。
- 真实成功路径使用本地 API。
- 浏览器检查按 [页面测试标识](../契约/接口与数据.md#错误与前端定位) 定位角色选择、创建表单、搜索和工单记录。

改动范围包括 `frontend/vue/`、`tests/learner/`、`learning/Q09/`。任务分支为 `feat/q09-real-integration`。

在 `exercises/Q09.ts` 独立完成 [`mergeVersions`](../核心编码契约.md#q09-mergeversions) 并补充三个自拟反例。单独提交后再继续工程改动。

## 提交材料

提交浏览器验证记录，重点覆盖创建、快速切换条件和版本冲突。

在培训仓库提交 PR，并将 PR 链接、完整提交 SHA、完成说明及 PR 截图上传培训系统。将检查记录整理到 `learning/Q09/`，格式见 [交付记录](../模板/交付模板.md)。

## 验收要求

通过浏览器验证真实创建并在刷新后按 ID 查找。分别复现 400、403、404、409 与网络中断，并记录失败场景的模拟方法。旧响应不得覆盖切换后的列表或详情。

```sh
npm run check:task -- Q09
npm test
npm run test:learner
npm run typecheck
npm run build
npm run test:acceptance -- Q09
npm run check:ui -- Q09
```
