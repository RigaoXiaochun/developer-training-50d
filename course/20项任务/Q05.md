# 开发培训任务 Q05

## 阶段验收一 · 工单界面

依据原型反馈材料复查共用控件、工单列表、新建和详情。记录发现的问题、修复内容和复测结果。准备演示选择上限的独立函数，按审核人提供的样例或上限现场修改。

- 以反馈条目为单位记录复现条件、修复范围及实际复测结果。

改动范围包括 `frontend/vue/`、`frontend/shared/`、`learning/Q05/`。任务分支为 `feat/q05-ui-quality-gate`。

在 `exercises/Q05.ts` 独立完成 [`toggleSelection`](../核心编码契约.md#q05-toggleselection) 并补充三个自拟反例。单独提交后再继续工程改动。

## 提交材料

提交验收版本、修复前后证据和界面回归记录。

在培训仓库提交 PR，并将 PR 链接、完整提交 SHA、完成说明及 PR 截图上传培训系统。将检查记录整理到 `learning/Q05/`，格式见 [交付记录](../模板/交付模板.md)。

## 验收要求

Q01 至 Q05 的核心函数检查应通过。界面评分至少 85 分，且主流程、长内容、键盘操作和四种页面宽度无阻断问题。现场以日语说明本阶段成果，控制在两分钟。

```sh
npm run check:task -- Q05
npm test
npm run test:learner
npm run typecheck
npm run build
```
