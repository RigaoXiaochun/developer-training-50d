# 开发培训任务 Q15

## 阶段验收三 · 代码审查

审查指定补丁，识别需求越界、错误吞并、SQL 拼接、权限放大和验证缺失。审阅自己的分支，整理数据、权限、共享控件、依赖和状态处理的改动。完成一次范围明确的重构并用相同测试复测。

- 审查时说明任何测试、权限或依赖变动的原因及其验收结果。

改动范围包括 `frontend/vue/`、`server/`、`tests/learner/`、`learning/Q15/`。任务分支为 `feat/q15-independent-code-review`。

在 `exercises/Q15.ts` 独立完成 [`patchRisk`](../核心编码契约.md#q15-patchrisk) 并补充三个自拟反例。单独提交后再继续工程改动。

## 完成后应能做什么

能审查 AI 生成或改写的代码，识别权限扩大、错误被吞、SQL 不安全和改动超出需求等问题，并用回归测试判断是否可以接收。

## 提交材料

提交审查意见、候选版本以及重构前后的检查结果。

在培训仓库提交 PR，并将 PR 链接、完整提交 SHA、完成说明及 PR 截图上传培训系统。将检查记录整理到 `learning/Q15/`，格式见 [交付记录](../模板/交付模板.md)。

## 验收要求

Q01 至 Q15 的基础检查应通过。重构后接口和数据约束符合原约定，界面评分至少 85 分。现场解释并修改抽取的一个核心函数与一条 SQL，并用日语说明一次审查取舍。

```sh
npm run check:task -- Q15
npm test
npm run test:learner
npm run typecheck
npm run build
npm run test:acceptance -- Q15
npm run check:ui -- Q15
```

本项安排现场验收。

コードレビューで何を優先して確認しますか。
