# 开发培训任务 Q06

## 工单接口与权限测试

核对 v1 接口的字段、空值、状态转换、错误优先级和三类角色权限。绘制 Actor、Ticket 和 Event 的关联，标明版本与归档字段。在 `tests/learner` 增加接口契约测试。

- 统计查询同样受角色与可见范围约束；新增测试与原基线断言分别保留。

改动范围包括 `learning/Q06/`、`tests/learner/`、`frontend/vue/types.ts`。任务分支为 `feat/q06-contract-first`。

在 `exercises/Q06.ts` 独立完成 [`parseListQuery`](../核心编码契约.md#q06-parselistquery) 并补充三个自拟反例。单独提交后再继续工程改动。

## 提交材料

提交接口与角色对照表、数据关系图、允许和拒绝两类请求的验证记录。

在培训仓库提交 PR，并将 PR 链接、完整提交 SHA、完成说明及 PR 截图上传培训系统。将检查记录整理到 `learning/Q06/`，格式见 [交付记录](../模板/交付模板.md)。

## 验收要求

新增测试需覆盖未知字段、非法页码、空结果、字段长度、访问他人记录和 409 冲突。提供一项故障注入记录，证明对应断言能发现问题。维持 v1 的请求、响应和错误码。

```sh
npm run check:task -- Q06
npm test
npm run test:learner
npm run typecheck
npm run build
```
