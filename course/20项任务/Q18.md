# 开发培训任务 Q18

## 性能测量与故障验证

在训练环境准备 10000 条工单，以 10 并发执行 500 次读取，并使用指定写入和冲突样本。记录环境、版本及预热方式。保留耗时、错误和超时样本，计算 p50、p95 与最大值。

- 保留全部测量样本并列出非预期错误数。故障演练核对虚假成功、重复创建、部分写入及事件完整性。

改动范围包括 `server/`、`frontend/vue/`、`tests/learner/`、`learning/Q18/`。任务分支为 `feat/q18-measured-reliability`。

在 `exercises/Q18.ts` 独立完成 [`summarizeSamples`](../核心编码契约.md#q18-summarizesamples) 并补充三个自拟反例。单独提交后再继续工程改动。

## 提交材料

提交测量脚本、原始样本、环境及前后对比，并说明数据支持的结论。

向培训仓库提交 PR。在培训系统填写 PR 链接、完整提交 SHA 和完成说明，上传 PR 截图。检查记录放在 `learning/Q18/`，格式见 [交付记录](../模板/交付模板.md)。

## 验收要求

用相同条件比较优化前后的结果。按最近秩法计算 p95，指定参考机器的列表 p95 目标为 300 ms，其他环境由审核人确认比较基线。验证数据库不可写、网络中断和版本冲突时的行为。

```sh
npm run check:task -- Q18
npm test
npm run test:learner
npm run typecheck
npm run build
npm run test:acceptance -- Q18
npm run check:ui -- Q18
```
