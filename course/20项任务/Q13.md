# 开发培训任务 Q13

## 工单游标分页

在独立训练库准备 10000 条工单并记录原列表查询、响应体积和 DOM 节点数。实现 `GET /v2/tickets` 游标列表，按 `createdAt DESC, id DESC` 排序，在 SQL 中筛选和限量，每次最多返回 100 条。

- 每次请求都验证游标并重新应用当前身份权限。保持 v1 接口兼容。

改动范围包括 `server/`、`frontend/vue/`、`tests/learner/`、`learning/Q13/`。任务分支为 `feat/q13-bounded-data-flow`。

在 `exercises/Q13.ts` 独立完成 [`selectAfter`](../核心编码契约.md#q13-selectafter) 并补充三个自拟反例。单独提交后再继续工程改动。

## 提交材料

提交同条件的优化前后数据、查询计划、重复与缺项检查和手机滚动记录。

在培训仓库提交 PR，并将 PR 链接、完整提交 SHA、完成说明及 PR 截图上传培训系统。将检查记录整理到 `learning/Q13/`，格式见 [交付记录](../模板/交付模板.md)。

## 验收要求

验证相同时间记录的排序、顶部新增记录后的连续翻页、角色与筛选切换以及旧响应处理。前端按 ID 和版本合并，控制 DOM 节点数。说明数据新增或删除对翻页的影响。

```sh
npm run check:task -- Q13
npm test
npm run test:learner
npm run typecheck
npm run build
npm run test:acceptance -- Q13
npm run check:ui -- Q13
```
