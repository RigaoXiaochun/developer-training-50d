# 开发培训任务 Q07

## 工单数据迁移至 SQLite

建立 `actors`、`tickets`、`events` 和 `schema_migrations` 表，把外键、唯一性、校验约束和索引写入版本化 SQL。更新仓储层，用参数化查询完成读写，列表筛选和分页由数据库执行。

- 在失败时保留数据；交付记录说明 SQLite 同步驱动在本地训练进程中的适用范围。

改动范围包括 `server/`、`tests/learner/`、`learning/Q07/`。任务分支为 `feat/q07-sql-repository`。

在 `exercises/Q07.ts` 独立完成 [`visibilityWhere`](../核心编码契约.md#q07-visibilitywhere) 并补充三个自拟反例。单独提交后再继续工程改动。

## 提交材料

提交迁移脚本、迁移前后核对结果、重启验证和失败恢复步骤。

在培训仓库提交 PR，并将 PR 链接、完整提交 SHA、完成说明及 PR 截图上传培训系统。将检查记录整理到 `learning/Q07/`，格式见 [交付记录](../模板/交付模板.md)。

## 验收要求

在独立训练库导入 25 条工单及关联事件。核对行数、引用、版本和归档状态，重启后再次核对，确保不重复导入。提交查询计划并验证数据可见范围。

```sh
npm run check:task -- Q07
npm test
npm run test:learner
npm run typecheck
npm run build
```
