# 开发培训任务 Q11

## 故障定位与回归测试

从缺陷材料 A、B、C 中选两项，在独立分支复现。保留触发步骤、请求结果和相关状态变化，用最小实验排除其他原因。完成修复并补充回归测试。

- 记录每项修复的影响范围与原有行为的回归结果。

改动范围包括 `frontend/vue/`、`tests/learner/`、`learning/Q11/`。任务分支为 `feat/q11-evidence-debugging`。

在 `exercises/Q11.ts` 独立完成 [`canRetry`](../核心编码契约.md#q11-canretry) 并补充三个自拟反例。单独提交后再继续工程改动。

## 提交材料

提交两项缺陷的复现步骤、根因说明和修复前后测试记录。

向培训仓库提交 PR。在培训系统填写 PR 链接、完整提交 SHA 和完成说明，上传 PR 截图。检查记录放在 `learning/Q11/`，格式见 [交付记录](../模板/交付模板.md)。

## 验收要求

同一测试应能在修复前发现缺陷，修复后通过。重点检查 POST 或 PATCH 被重复执行、失败被页面显示为成功，以及旧响应覆盖新结果等风险。

```sh
npm run check:task -- Q11
npm test
npm run test:learner
npm run typecheck
npm run build
npm run test:acceptance -- Q11
npm run check:ui -- Q11
```
