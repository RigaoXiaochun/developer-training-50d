# 开发培训任务 Q03

## 共用控件与响应式布局

画出桌面 1440 px 和手机 390 px 的列表、表单与详情线框，明确各宽度保留的信息和操作。沿用现有设计变量，实现按钮、输入控件、状态标签和确认弹窗，并依据原型反馈材料完成两轮调整。

可参考 [从手机界面反馈到原型的示范](../固定材料/业务原话练习.md#q03q04--把界面反馈变成原型验证)，把实际看到的问题转成一条可复测的原型任务。

- 区分页头、导航、筛选、列表、详情及主次操作；检查 Flex 最小宽度和触摸目标。

改动范围包括 `frontend/shared/`、`frontend/vue/components/`、`frontend/vue/style.css`、`learning/Q03/`。任务分支为 `feat/q03-design-system`。

在 `exercises/Q03.ts` 独立完成 [`controlState`](../核心编码契约.md#q03-controlstate) 并补充三个自拟反例。单独提交后再继续工程改动。

## 完成后应能做什么

能把「手机上不好用」转成明确的布局与交互条件，用 AI 做一段小原型，再通过不同宽度、键盘和长文本实测，收敛到一套共用控件。

## 提交材料

提交线框、控件示例、两轮调整记录和各尺寸验证结果。

在培训仓库提交 PR，并将 PR 链接、完整提交 SHA、完成说明及 PR 截图上传培训系统。将检查记录整理到 `learning/Q03/`，格式见 [交付记录](../模板/交付模板.md)。

## 验收要求

在 320、390、768 和 1440 px 下检查控件和布局。验证 200% 缩放、键盘焦点、长文本和禁用状态。列表、表单和详情使用同一套控件样式。

```sh
npm run check:task -- Q03
npm test
npm run test:learner
npm run typecheck
npm run build
```
