# UI与交互标准

各项任务沿用同一套工单界面和 [设计变量](../design-tokens.json)。布局与控件样式见 [界面参考](../reference/index.html)。

桌面：224px侧栏、64px页头、主要内容最大1120px、24px内边距；表单最大640px。手机：16px内边距、稳定页头、可触达导航和底部安全区。检验320／390／768／1440 CSS像素，至少提供390与1440截图。

字体正文16px、标题24px；间距4／8／12／16／24／32px；控件高44px、圆角8px，卡片12px；颜色取tokens。主次操作有层级，危险操作明确、二级确认。所有textarea禁止手工resize，长段落自然换行，连续字符串不撑开布局。

列表可省略标题，但详情能读全文；名称／状态不挤掉操作。手机可由表格变卡片，保持字段与行为一致。加载、空态、失败、处理中、冲突分别有清晰反馈；失败保留输入，成功有真实响应依据。

可见label、焦点环、键盘可用、dialog支持Escape与焦点返回；正文对比度4.5:1。主要触摸目标44×44px是课程标准。输入字体至少16px，200%缩放关键操作仍可用。实机键盘无法验证须注明，不以模拟器等价通过。

|评分维度|分值|
|---|---:|
|变量与组件一致性|20|
|信息层级、主次操作和业务文案|20|
|对齐、留白、视觉密度|15|
|四宽度与极端内容|20|
|表单、错误、冲突和恢复|15|
|键盘、焦点、标签与对比度|10|

阶段验收至少 85 分，并须排除阻断项，包括关键内容不可访问、操作被覆盖、弹窗无法退出、失败显示为成功或主流程无法完成。

不因UI调整改变业务权限、接口或数据口径；共享样式调整必须回归列表、详情、表单、批量与错误态。
