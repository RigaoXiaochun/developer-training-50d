# 训练与验收要求

按 [任务目录](../总览.md) 开展训练。每位学员通过前置审核后，培训系统分配下一项并显示截止时间。

每项先完成独立编码。关闭代码生成和补全，独立实现 `exercises/Qxx.ts` 的核心函数。把至少三个自己设计的反例写到 `tests/learner/qxx.test.mjs`，将这两类改动单独提交。这里的 `Qxx` 和 `qxx` 换成任务编号。即使任务书列出的工程改动范围较窄，这两个路径也适用。工程部分允许使用辅助工具，学员负责审查改动并执行验证。

先运行 `npm run test:core -- Qxx` 检查当前函数，再运行 `npm run test:learner` 运行自己的用例。填写 [四份交付记录](../模板/交付模板.md) 后，运行 `npm run check:task -- Qxx`。这一步会检查截至本题的全部核心函数及当前题的记录。从上一项通过版本继续开发。

提交要求以任务书为准。培训系统收取 PR 链接、完整 Git SHA、完成说明及验证附件。验收依据为对应版本的源码、测试结果和现场演示。需要补做时，按审核意见更新同一 PR 后重新提交。

Q05、Q10、Q15、Q20 安排现场验收。现场说明应围绕实际实现、异常处理和验证结果，并完成审核人指定的修改。日语说明及技术核验分别记录。
