# 开发辅助工具使用规范

## 独立编码

每项先独立完成 `exercises/` 中的核心函数和自拟反例。完成单独提交后，工程修改可以使用辅助工具。若工具已给出当前独立题的实现，本次作为练习，由审核人另选样例完成独立核验。

## 实施与审查

- 开始前记录本项要解决的问题、涉及文件、约束及验收方法。接口、数据结构、共享控件或依赖有变动时，写明理由并核对受影响的调用方。
- 审阅待提交差异，确认权限、状态转换、错误反馈、界面与数据处理符合任务要求。关键假设通过测试或最小复现核验。
- 记录实际执行的命令、结果与未覆盖情形。仓库记录保留与改动有关的内容，去除账号资料及其他内部信息。

Q03、Q04 按 [原型反馈](../固定材料/原型反馈与迭代.md) 开展界面评审。每轮记录操作场景、发现的问题、修改位置及复测结果。
