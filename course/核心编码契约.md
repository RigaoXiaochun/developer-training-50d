# 核心函数规范

完成核心函数时关闭代码生成和补全，可以查阅文档。纯函数应保留输入原值，返回数组按各题规定排序，对象键顺序不限。现场验收会使用新的测试样例。

## Q01 normalizeDraft

```ts
export function normalizeDraft(draft: Record<string, unknown>): { value: { title: string; description: string; category: string } | null; errors: { field: string; code: string }[] }
```

- 只读取title、description、category；不修改输入。title与description为字符串，trim后分别1—60、1—1000 Unicode码点。
- category仅support／billing／other，严格匹配不隐式改值。错误按title、description、category固定顺序，code统一INVALID。
- 任一错误value=null，合法errors=[]并返回规范三字段，不携带未知字段。

测试样本在core-specs.json，另需本人补3个边界／反例。

## Q02 parseBranch

```ts
export function parseBranch(name: string): { kind: string; task: string; slug: string } | null
```

- 格式为kind/qNN-slug，kind仅feat／fix／refactor，NN范围01—20，例如feat/q01-requirements。
- slug由小写字母开头的小写字母／数字词段，以单个短横线分隔；不能连续横线或尾横线。
- 合法返回kind、转大写的QNN和slug，非法返回null，不trim输入。

## Q06 parseListQuery

```ts
export function parseListQuery(query: Record<string, string | undefined>): { q: string; status: string; page: number; pageSize: number }
```

- 只支持q、status、page、pageSize；未知键抛status400/code=UNKNOWN_QUERY。
- q缺省空字符串，trim、最长120 UTF-16单元；status缺省或空为all，否则仅all/open/in_progress/resolved，非法状态抛400 INVALID_STATUS。
- page缺省1，纯十进制数字且1—100000；pageSize缺省5，仅5/10/20。显式空页码非法，非法分页／超长q抛400 INVALID_QUERY。

## Q08 canUpdate

```ts
export function canUpdate(actor: Actor, ticket: Ticket, patch: Record<string, unknown>): boolean
```

- 归档或不可见false，patch必须有等于当前version的正整数version及至少一个业务字段。
- user仅本人open，业务字段只能title/description/category；staff仅本人分配，字段只能status，允许open→in_progress/resolved、in_progress→resolved。
- manager可见全部有效，业务字段仅status/assigneeId；status若出现需三种合法值。其他未知角色、字段或空修改false。
- 本函数只判断范围、字段和状态；文本内容与assignee存在性由服务端独立校验，不要凭空在此放宽权限。

## Q09 mergeVersions

```ts
export function mergeVersions(current: Ticket[], incoming: Ticket[]): Ticket[]
```

- 两数组内部id均唯一。保留current的id顺序，新id按incoming出现顺序追加。
- 同id仅incoming.version更高时替换；相同或较低版本保留current。返回新数组，不改记录和输入数组。
- 这只是视图合并工具，不能用它绕过服务端版本保护。

## Q10 classifyFailure

```ts
export function classifyFailure(status: number | null, code: string): string
```

- status=null视为网络不可用，返回unavailable。400→validation，401→identity，403→permission，404→not_found，409→conflict，429→rate_limit，500—599→unavailable，其余unknown。
- code保留在调用者的错误对象中，本函数不靠任意message猜错误类别，也不改变输入。

## Q11 canRetry


- 仅GET（不区分大小写）在null网络失败或502／503／504时可重试。

## Q12 checkBulkVersions

```ts
export function checkBulkVersions(tickets: { id: string; version: number }[], commands: { id: string; version: number }[]): { validIds: string[]; conflicts: string[]; missing: string[] }
```

- commands 1—100项，空抛400 INVALID_BULK，超100抛400 BULK_LIMIT，重复id抛400 DUPLICATE_ID；这些检查在分类之前。
- tickets为已按权限过滤的当前记录，id唯一。按commands顺序分别分类：不存在missing，version不同conflicts，相同validIds。
- 不修改输入，不进行写入。服务端若任何缺失／冲突必须整体拒绝，不能用validIds偷偷部分提交。

## Q13 selectAfter

```ts
export function selectAfter(items: Ticket[], cursor: { createdAt: string; id: string } | null, limit: number): { items: Ticket[]; nextCursor: { createdAt: string; id: string } | null }
```

- 输入记录的createdAt为同格式ISO UTC、id唯一；先按createdAt倒序，同时间按id字典倒序。
- cursor=null从头；否则仅返回时间小于cursor，或时间相同且id字典小于cursor的记录。limit整数1—100，非法抛400 INVALID_LIMIT。
- 取limit项，若还有更多则nextCursor为本页最后一项位置，否则null；空页null。不改输入。
- 这是学习边界算法的纯函数，不是允许服务端将10000条读进内存再分页；实际API必须SQL LIMIT。

测试样本在core-specs.json，另需本人补3个边界／反例。

## Q14 changedFields

```ts
export function changedFields(original: Record<string, unknown>, draft: Record<string, unknown>, allowed: string[]): Record<string, unknown>
```

- 未知草稿键不输出；draft没有提供的字段视为不修改，不自动清成null。

## Q15 patchRisk

```ts
export function patchRisk(paths: string[]): { level: string; areas: string[] }
```

- 路径已是仓库相对路径，先将反斜线转正斜线。migrations/或server/migrations/→schema；server/policy开头→auth；frontend/vue/components/开头→shared_ui；根package.json或package-lock.json→dependency；其余feature。

## Q17 threeWayMerge

```ts
export function threeWayMerge(base: Record<string, unknown>, local: Record<string, unknown>, remote: Record<string, unknown>): { merged: Record<string, unknown>; conflicts: string[] }
```

- 三个输入有相同自身键集合，值为string／number／boolean／null；按键字典序处理。
- local==remote取该值；local==base取remote；remote==base取local；其余为冲突，键加入conflicts且不放入merged。
- 返回新对象，不修改任何输入；不要以本地或远端优先掩盖真实冲突。

## Q18 summarizeSamples

```ts
export function summarizeSamples(samples: number[]): { count: number; p50: number | null; p95: number | null; max: number | null }
```

- samples为毫秒值，所有值须有限且非负，非法抛400 INVALID_SAMPLE。
- 升序后nearest-rank百分位：索引ceil(p*N)-1，p50使用0.5、p95使用0.95；max保留最慢值。
- 空集count=0其余null；不改输入，不删异常慢但合法的样本。
